## About DHYAN

**DHYAN** is a book exchange platform where people can list books they don't
need anymore and request books from others in their community — basically a
mini marketplace for sharing books.

Started as a frontend-only demo with fake data stored in the browser, and is
now being rebuilt with a real Java backend (Servlets + JSP) and a MySQL
database — so it works like a real app, with real accounts, real data, and
real login.
